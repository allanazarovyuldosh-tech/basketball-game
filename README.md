# 🏀 Basketball Game | Баскетбольная Дуэль

Интерактивная браузерная игра в баскетбол с прогрессивной сложностью, звуком и отслеживанием рекордов.

[**Играть онлайн**](https://allanazarovyuldosh-tech.github.io/basketball-game/)

---

## 🎮 Как Играть

1. **Нажмите кнопку** "Начать игру!" чтобы начать раунд
2. **Удерживайте кнопку** для накопления силы броска
3. **Отпустите** чтобы бросить мяч в кольцо
4. **Точность** — бросок должен быть в диапазон 55-82% силы
5. **Уровни** — каждые 5 очков уровень растет, кольцо начинает двигаться!

---

## ✨ Особенности

- 🎯 **Динамическая сложность** — с каждым уровнем кольцо движется быстрее
- 🔊 **Звуковые эффекты** — Web Audio API для атмосфиры
- 💾 **Рекорды** — сохраняется лучший результат в localStorage
- ⏱️ **Таймер** — 30 секунд на раунд
- 📱 **Мобильное-дружественное** — поддержка touch и mouse
- 🎨 **Красивый UI** — градиентный фон, анимации, визуальный feedback
- ⭐ **Много уровней** — растущая сложность и кол-во очков за попадание

---

## 🏆 Геймплей

| Статистика | Описание |
|-----------|---------|
| **Очки** | За каждое попадание вы получаете очки равные текущему уровню |
| **Уровень** | Повышается каждые 5 очков, кольцо начинает двигаться |
| **Время** | 30 секунд за раунд |
| **Рекорд** | Сохраняется и показывается внизу экрана |

## 📝 Правила Попадания

Мяч попадает в кольцо если **сила броска в диапазоне:**
- ✅ **55% - 82%** → Гол! ✓
- ❌ **Меньше 55%** → Недолет
- ❌ **Больше 82%** → Перелет

---

## 🎵 Звуки

- 🔊 **Charge** — при накоплении силы
- 🎯 **Goal** — при попадании
- ❌ **Miss** — при промахе

Все звуки генерируются в реальном времени с помощью Web Audio API

## 💾 Сохранение Данных

Ваш лучший результат сохраняется в браузере используя `localStorage`. Если вы очистите данные браузера, рекорд сбросится.
